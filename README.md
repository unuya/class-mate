# 수업 메이트

처음 바이브코딩하는 교사를 위한 Gemini Canvas 교육용 웹앱 제작 요청문 도우미입니다.

학년·교과·학습 목표와 활동을 입력하고 요청문을 복사해 Gemini Canvas에 붙여넣으세요.

HTML, CSS, JavaScript로 구성되어 설치와 API 키가 필요하지 않습니다. 입력은 현재 브라우저에만 저장됩니다. Google Fonts를 사용하며 연결되지 않으면 시스템 글꼴로 표시됩니다.

## 실행

index.html을 브라우저에서 열거나 GitHub Pages의 main 브랜치 / (root)를 배포합니다.
